Aion 2 lanzó globalmente el 5-oct-2026 (Early Access 30-sep-2026). Último hotfix: 6-oct PDT / 7-oct CEST 2026. Season 1 vigente hasta 16-dic-2026.

**Diferencias críticas Global vs KR Chapter 1 (lo que invalida guías viejas):**
- Cap de nivel GLOBAL = **45** (KR = 50). No usar 50 como cap.
- Stigma cap = **Lv20** (KR = Lv25). Illusive Clone "permanente" tier 25 NO existe en global.
- **4 slots de stigma** (KR = 6). Desbloqueos: Lv22, 27, 32, 37.
- **Pet level cap = 3** (KR = 5). Insight Lv2 = Mount Glide, Lv3 = Transformation.
- **8 clases** disponibles (sin Brawler). Asesino sí incluido.
- **Sin ítems Heroic rarity** durante Season 1.
- Zonas **Eltnen/Morheim** bloqueadas (están en archivos pero no accesibles por cap 45).
- **Ludra** dungeon removido temporalmente desde 5-oct, retorno estimado 16-oct-2026.
- Parties de 5 jugadores sí incluidas desde launch.

**Why:** Hay muchas guías circulando (incluso web 2upskill, metabot, aion2.run) que mezclan info de KR Chapter 1 con global, confundiendo al jugador. Usuario pidió explícitamente "ignora cualquier información que no esté acorde a la última actualización".

**How to apply:**
- Al generar cualquier guía/build/rotación de Aion 2 global, usar cap 45 y stigma Lv20
- Si una fuente menciona lv50, Illusive Clone permanente, 6 stigmas, pet lv5 → descartar o marcar como KR-only
- Rangos de skill priorizados: Heart Gore / Insignia Explosion / Quick Slice a Lv20 primero
